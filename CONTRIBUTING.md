# Contributing

Thank you for helping improve the Stackiln website and documentation.

1. Search existing issues and pull requests.
2. Open an issue before a substantial information-architecture or visual change.
3. Create a focused branch and keep the change small.
4. Run `pnpm verify`.
5. Open a pull request explaining the user-facing result.

Use the framework repository for changes to Stackiln itself. By contributing, you agree that your contribution is licensed under the MIT License and that you will follow the [Stackiln Code of Conduct](https://github.com/Stackiln/stackiln/blob/main/CODE_OF_CONDUCT.md).
