# Security policy

Do not report a vulnerability in a public issue.

Use the private security-advisory form in the relevant Stackiln repository. Include affected routes or versions, reproduction steps, impact, and any suggested mitigation. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

For vulnerabilities in the generated framework or CLI, report them through the [Stackiln framework repository](https://github.com/Stackiln/stackiln/security/advisories/new).
